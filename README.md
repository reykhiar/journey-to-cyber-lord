# Journey to Cyber Lord
Repositori ini berisi dokumentasi perjalanan belajar cybersecurity, catatan teknis, laporan lab praktik, dan proyek portofolio yang saya bangun secara mandiri.

## Ringkasan Repositori
Repositori ini berfungsi sebagai pusat dokumentasi pengalaman praktis saya di bidang keamanan siber. Di sini saya mencatat perkembangan kemampuan mulai dari fundamental sistem operasi & jaringan, pembuatan skrip otomasi keamanan, hingga analisis kerentanan dan pengujian sistem.

## Struktur Repositori
journey-to-cyber-lord/
├── 01-fundamentals/    # Catatan dasar administrasi Linux dan perintah terminal
├── 02-networking/      # Protokol jaringan, analisis lalu lintas data, dan diagnosa DNS/HTTP
├── 03-scripting/       # Skrip otomasi keamanan menggunakan Bash & Python
├── 04-labs/            # Laporan praktik CTF dan pengujian lab kerentanan
├── 05-projects/        # Proyek alat/aplikasi cybersecurity utama
└── docs/               # Aset gambar, tangkapan layar (screenshots), dan diagram

## Alat & Teknologi
- **Sistem Operasi:** Linux
- **Bahasa Pemrograman / Skrip:** Bash, Python
- **Alat Diagnostik Jaringan:** `curl`, `dig`, `nslookup`, `wireshark`
- **Alat Reconnaissance:** `subfinder`, `nmap`
- **Manajemen Versi:** Git, GitHub

## Batasan Etika (Ethical Disclaimer)
Seluruh materi, skrip, dan dokumentasi di dalam repositori ini dibuat murni untuk tujuan edukasi dan riset keamanan siber secara etis. Seluruh pengujian dan eksekusi skrip hanya dilakukan pada lingkungan lokal/lab atau target yang memiliki izin resmi.
